## The numbers

No fee. The strong basket against holding every name in that same test. Sharpe uses each month's ups and downs, and cash earns nothing. A higher Sharpe is a smoother ride for the return you got. Alpha is the yearly extra after giving credit for how much the basket bounced with every name. Beta near 1 means it bounced about as much as every name. Return per unit of fall is the yearly return divided by the worst fall.
